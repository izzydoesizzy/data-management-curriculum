1. Learn 20 min

Look at the diagram on the practice data page again. Our data is a star schema:

  • Services is the fact table in the middle. It records events and has lots of rows.
  • Clients, ServiceCodes and Workers are dimension tables around it. They describe the who and what, with one row each.
  • Each link is one-to-many: one client → many services; one code → many services; one worker → many services.

In Looker Studio you connect tables with a blend: you pick a main table (Services) and join the others to it on their ID columns. Every chart built on the blend can then use fields from all four tables, so you can show "services by Program" even though Program lives in Clients.

Read: Create, edit, and manage blends (Google).

2. Do 35 min

  1. Create the blend. Resource → Manage blends → Add a blend. For the first table choose Services. Add all its fields as dimensions: ServiceID, ClientID, ServiceDate, ServiceCode, WorkerID, DurationMins and UnitCost. (Keeping them as dimensions keeps one row per service; you'll build your own totals in Week 11.)
  2. Join Clients. Click Join another table → Clients. Dimensions: Program, Region, AgeBand, IntakeDate, DischargeDate. Click the join box between them → Left outer → join condition ClientID = ClientID → Save.
  3. Join ServiceCodes the same way: dimensions Description and Category; Left outer on ServiceCode = ServiceCode.
  4. Join Workers: dimensions Name and Role; Left outer on WorkerID = WorkerID.
  5. Name the blend Casework Model (top of the blend editor) → Save. That's three joins, Looker Studio's version of relationships.
  6. Prove it works. Insert → Bar chart. Data source = Casework Model. Dimension = Program, Metric = ServiceID set to Count. Each program shows a different number of services, even though Program lives in another table.
  7. Find the clients with no services. Add two scorecards: one on the Clients data source with ClientID set to Count Distinct, one on Services with ClientID set to Count Distinct. The difference is clients on the books who have never received a service.
Stuck? Try this
  • Bar chart shows "null" as a program: a join key doesn't match. Check the join condition is ClientID = ClientID, and that you're using the Week 9 clean data.
  • Totals are bigger than expected: make sure Services is the first (left) table and every join is Left outer.
  • Can't find Manage blends: you need to be in Edit mode. Or select a chart, then in Setup click Blend data under the data source.
