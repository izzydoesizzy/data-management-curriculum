1. Learn 15 min

A pivot table has four boxes you fill from the editor panel on the right:

  • Rows: what you want one line per (e.g. Program)
  • Columns: what to split across the top (e.g. Category)
  • Values: the number to calculate (e.g. SUM of UnitCost)
  • Filters: what to narrow the whole thing by

A slicer is a clickable filter that sits above the pivot table, the same idea as the filter controls in Looker Studio.

Read: Create & use pivot tables (Google). Google Sheets version of the spec: same two pivot tables, on tabs named Pivot - Program and Pivot - Top Clients.

2. Do 60 min

  1. Add Program and Region to Services (skip Program if you did it in the Week 4 stretch). In I1 type Program, and in I2: 
    =ARRAYFORMULA(IF(B2:B = "", , XLOOKUP(B2:B, Clients!A:A, Clients!D:D)))
    In J1 type Region, and in J2 use the same formula with Clients!E:E.
  2. Insert the pivot table. Click any cell in Services → Insert → Pivot table. Check the range covers all columns (A1:J…) → New sheet → Create. Rename the new tab Pivot - Program.
  3. In the editor on the right: Rows → Add → Program. Columns → Add → Category. Values → Add → UnitCost, summarized by SUM.
  4. Format numbers. Select the pivot's numbers → Format → Number → Currency rounded.
  5. Add a slicer. Click the pivot table → Data → Add a slicer. In the slicer panel set the column to Region. Click the slicer and pick a region to filter. Set it back to all when done.
  6. Second pivot table. From Services again, Insert → Pivot table → New sheet. Rename the tab Pivot - Top Clients. Rows = ClientID, Values = SUM of UnitCost.
  7. Sort. Under Rows → ClientID → Order: Descending, Sort by: SUM of UnitCost. The top 10 rows are your top 10 clients.
Stuck? Try this
  • Pivot editor disappeared? Click a cell inside the pivot table and click Edit under it.
  • UnitCost isn't offered as SUM: the column contains text. Check Week 4's formula.
  • Grand totals don't match Week 4? Check the slicer is set to all regions, and the pivot range includes every row.
