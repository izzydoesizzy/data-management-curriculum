Read: VSTACK function (Google). Google Sheets version of the spec: in Casework Recipe, rename the Clean tab to AllServices. It should contain both months, cleaned, plus UnitCost and Category columns.

2. Do 60 min

  1. Open Casework Recipe.
  2. Load the price list. File → Import → Upload → service_codes.csv → Insert new sheet(s). Rename the tab ServiceCodes.
  3. Load next month. Import services_2026-09.csv the same way. Rename the tab Sep.
  4. Append. Rename the Clean tab to AllServices. Edit the formula in A2: change just the raw line so it stacks both months: 
      raw,  VSTACK(Raw!A2:F, Sep!A2:F),
    The cleaning rules now run on both files at once.
  5. Merge in the price list. In G1 type UnitCost, and in G2: 
    =ARRAYFORMULA(IF(D2:D = "", , XLOOKUP(D2:D, ServiceCodes!A:A, ServiceCodes!D:D, "NOT FOUND")))
    In H1 type Category, and in H2 use the same formula with ServiceCodes!C:C.
  6. Answer the questions. In J1: =COUNTA(A2:A) (rows). In J2: =SUM(G2:G) (total spend). In J3, September only: 
    =SUMIFS(G2:G, C2:C, ">=" & DATE(2026, 9, 1))
  7. Next month, for real: import the new export into a new tab and add it to the VSTACK. That's the whole monthly update.
Stuck? Try this
  • UnitCost shows NOT FOUND: check the tab is named ServiceCodes and the codes in AllServices are clean (UPPER/TRIM).
  • Row count is a bit high: the raw line must stack the two ranges inside the same cleaning formula, so both months get cleaned.
  • September sum is $0: ServiceDate imported as text. Re-import with Convert text to numbers, dates, and formulas ticked.
