1. Learn 15 min

Raw data vs. reports

A report is a summary: "Housing Support spent $358K this year." Raw data is the list of every single event behind it: each home visit, each rent supplement, each phone call. You can always build a report from raw data, but you can never get the raw data back from a report. That's why colleagues pulled raw data into their own tools: it let them ask their own questions.

What a good raw table looks like ("tidy data")

  • One row = one thing. In our services file, one row = one service, delivered to one client, on one day.
  • One column = one kind of fact. A date column only has dates. A cost column only has numbers.
  • One header row, at the top. No titles above it, no merged cells, no subtotal rows sprinkled in.
  • An ID column that connects to other tables (ClientID, ServiceCode, WorkerID).

2. Do 40 min

  1. Download the data. On the practice data page, click Download everything. Double-click the .zip in your Downloads folder to unzip it.
  2. Create your spreadsheet. Go to sheets.google.com (any Google account) → Blank spreadsheet. Click the title "Untitled spreadsheet" and rename it Casework Practice.
  3. Import the services file. File → Import → Upload → choose services_raw.csv. Import location: Replace current sheet. Leave Convert text to numbers, dates, and formulas ticked → Import data. Double-click the tab at the bottom and rename it Services.
  4. Add the other three tables as tabs. File → Import → Upload → clients.csv → Import location: Insert new sheet(s). Rename the tab Clients. Do the same for service_codes.csv (tab name ServiceCodes) and workers.csv (tab name Workers).
  5. Freeze the header row on each tab so it stays visible as you scroll: View → Freeze → 1 row.
  6. Get around fast. On the Services tab, click cell A1, then press ⌘ + ↓ to jump to the last row. ⌘ + ↑ jumps back up. Look at the row number on the left of the last row.
  7. Explore. Scroll through each tab for 5 minutes. Find a client in Clients, then find a few of their services in Services. Look up what their service codes mean in ServiceCodes.
  8. Google Sheets saves automatically. Find it later in Google Drive.
Stuck? Try this
  • Row count off by one? The last row number includes the header row in row 1. Subtract 1.
  • Another way: click the column letter A, then look at the box at the bottom-right of the window. Switch it to Count; it includes the header.
  • Import didn't create a new tab? In the Import dialog, choose Insert new sheet(s) as the import location.
