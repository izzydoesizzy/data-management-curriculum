1. Learn 15 min

Your data is a block of cells with a header row. Two habits turn it into something you can question:

  • One table per tab, with a clear tab name (Clients, Services…). Formulas later refer to columns like Clients!D:D, which means "column D of the Clients tab".
  • A filter on the header row, which gives you sort and filter buttons on every column.

Read: Sort & filter your data (Google, 5 min).

2. Do 40 min

  1. Add a filter to Clients. Click any cell in the Clients data → Data → Create a filter. Filter icons appear in every header.
  2. Check your tab names. They must be exactly Services, Clients, ServiceCodes and Workers. Formulas later depend on them.
  3. Sort. In Clients, click the filter icon on IntakeDate → Sort A → Z. The oldest intake is now at the top. Sort ClientID A → Z again to put things back.
  4. Filter by one value. Click the filter icon on Program → Filter by values → Clear → tick Housing Support → OK. Click the column A letter and read Count at the bottom-right (switch it from Sum to Count if needed). Subtract 1 for the header.
  5. Clear the filter (Program filter icon → Select all → OK).
  6. Find active clients. A blank DischargeDate means the client is still active. DischargeDate filter icon → Filter by values → Clear → tick (Blanks) → OK. Count the ClientIDs the same way.
  7. Clear all filters (Data → Remove filter).
Stuck? Try this
  • No filter icons? Click inside the data first, then Data → Create a filter.
  • Count looks too big? Check the filter icon in the header shows it's active, and subtract 1 for the header.
  • (Blanks) not in the list? It's at the top or bottom of the values list. Click Clear first, then tick it.
