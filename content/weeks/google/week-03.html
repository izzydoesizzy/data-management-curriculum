1. Learn 15 min

Our export has four problems, all very common in real systems:

ProblemExampleFix in Google Sheets
Extra spaces"HV01 "TRIM() (or Data → Data cleanup → Trim whitespace)
Inconsistent case"hv01"UPPER() makes everything capitals
Duplicate rowsSame ServiceID twiceData → Data cleanup → Remove duplicates
Missing valuesBlank ServiceCodeFilter for blanks and delete those rows

Our three cleaning rules (used for every answer in this course):

  1. Service codes: trim spaces and convert to upper case.
  2. Remove exact duplicate rows.
  3. Remove rows with a blank service code.

Read: TRIM function (Google).

Before you start: make a backup. File → Make a copy → name it Casework Practice - before cleaning. Keep working in the original. Professionals never clean the only copy.

2. Do 50 min

  1. See the mess. On the Services tab, Data → Create a filter, then open the filter on ServiceCode → Filter by values. You'll see blanks and odd-looking duplicates. Close it.
  2. Add a helper column. In G1 type CodeClean. In G2 type this one formula, which fills the whole column: 
    =ARRAYFORMULA(IF(A2:A = "", , UPPER(TRIM(D2:D))))
    In plain English: "for every row that has data, take the code, trim it and make it upper case".
  3. Replace the original codes with the clean ones. Click G2, press ⌘ + Shift + ↓ to select down to the last row, then ⌘ + C. Click D2 → Edit → Paste special → Values only (⌘ + Shift + V). Start at row 2 so you don't overwrite the header.
  4. Delete the helper column. Right-click the G column letter → Delete column.
  5. Remove duplicates. Data → Remove filter first. Click the top-left corner box to select everything → Data → Data cleanup → Remove duplicates → tick Data has header row → Select all columns → Remove duplicates. Sheets tells you how many it removed. Write that number down.
  6. Remove blank codes. Data → Create a filter → ServiceCode filter → Filter by values → Clear → tick only (Blanks) → OK. Select the visible rows (click the first row number, then Shift-click the last) → right-click → Delete selected rows. Then Data → Remove filter.
  7. Count what's left. Click column A's letter and read Count at the bottom-right (minus 1 for the header).
