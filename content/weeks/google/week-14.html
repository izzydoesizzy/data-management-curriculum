Looker Studio version of the spec: same layout. Slicers = drop-down list controls, cards = scorecards, line chart = time series with ServiceDate as Year Month. Use the Casework Model blend for every chart and control, so the filters affect everything.

Session 1 60 min

  1. Add a new page (Page → New page). Rename it Cost Dashboard (Page → Manage pages).
  2. Title: Insert → Text. Type the title, size 20, bold.
  3. Controls: Insert → Drop-down list, data source Casework Model, Control field = Region. Repeat for Program and Role. Line them up along the top.
  4. Scorecards: four in a row, for Total Spend, Clients Served, Avg Spend per Client and Total Services (copy them from Week 11). Use Arrange → Align to line them up.
  5. Spend by Program (bar chart, sorted descending, data labels on under Style) and Monthly Spend (time series).

Session 2 60 min

  1. Spend by Category bar chart, sorted descending.
  2. Client Detail table: Dimensions ClientID, Program, Region; Metrics Total Services, Total Spend; sort by Total Spend descending.
  3. Tidy up: same widths, consistent gaps, all titles the same size (Style → Chart title).
  4. The 5-second test: click View (top-right) and show it to someone. In 5 seconds, can they say what the agency spent and where most of it goes?
  5. Use it. In View mode, set the controls to answer the checkpoints below, then reset them.
Stuck? Try this
  • A control doesn't filter a chart: controls only filter charts that use the same data source. Make sure every chart uses the Casework Model blend.
  • Role control is empty: the Workers join (Week 10) is missing Role as a dimension. Edit the blend and add it.
  • Scorecards show 846.4K: Style → turn off Compact numbers.
  • Want drill-through? Looker Studio uses cross-filtering instead: in View mode, click a program's bar and every other chart filters to it. Click again to clear. For a client profile page, add a ClientID drop-down control on a second page.
