1. Learn 15 min

  • Looker Studio understands dates. You can show any date field as a Year Month to group services by month, with no extra column needed.
  • Length of stay = days between IntakeDate and DischargeDate. Only discharged clients have one; active clients are left out automatically because their difference is empty (null), and averages ignore nulls.

Read: Dates and times (incl. DATE_DIFF) (Google).

2. Do 45 min

  1. Monthly trend. Insert → Time series chart, data source Casework Model. Dimension = ServiceDate; click the small calendar icon next to it and choose Year Month. Metric = Total Spend.
  2. Find the numbers. Hover over points, or add a Table with ServiceDate (Year Month) and Total Spend, then click the Total Spend header to sort.
  3. Length of stay field. Resource → Manage added data sources → Edit Clients → Add a field. Name Days Stayed, formula: 
    DATE_DIFF(DischargeDate, IntakeDate)
    Save → Done.
  4. Average it. Insert → Scorecard, data source Clients, metric Days Stayed with aggregation Average. Show 1 decimal place (Setup → metric → decimal precision).
  5. Try it by program: a table on Clients with Program and Average of Days Stayed.
Stuck? Try this
  • No calendar icon / dates look like text: set the field type to Date in the data source editor.
  • DATE_DIFF error: both IntakeDate and DischargeDate must be Date type.
  • Length of stay is a huge negative number: the order is DATE_DIFF(later, earlier), so discharge comes first.
  • Months out of order: time series charts sort by date automatically; in a table, sort by ServiceDate ascending.
