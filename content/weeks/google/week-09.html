1. Learn 15 min

Looker Studio is Google's free dashboard tool. It reads directly from Google Sheets, so when the Sheet changes, the dashboard updates. Three parts you'll use constantly:

  • Data sources: each tab of your Sheet becomes a data source (a table).
  • Charts and controls: add from the Insert menu, then choose fields in the Setup panel on the right, like filling a pivot table.
  • Edit vs. View mode: you build in Edit; others click around in View.

Read: Create a report from Google Sheets (Google).

2. Do 50 min

  1. Put the clean data in one Google Sheet. Upload powerbi-starter.xlsx to Google Drive (New → File upload). Double-click it, then File → Save as Google Sheets. Rename it Casework Data. It has tabs for Services, Clients, ServiceCodes and Workers (plus two for the Caseworks track).
  2. Add a UnitCost column to Services (Looker Studio works best when the cost is already on each row). On the Services tab, in G1 type UnitCost and in G2: 
    =ARRAYFORMULA(IF(D2:D = "", , XLOOKUP(D2:D, ServiceCodes!A:A, ServiceCodes!D:D)))
    Exactly what you did in Week 4.
  3. Create a report. Go to lookerstudio.google.com → Create → Report → Google Sheets → Casework Data → worksheet Services → keep Use first row as headers ticked → Add.
  4. Add the other tabs as data sources. Resource → Manage added data sources → Add a data source → Google Sheets. Add Clients, ServiceCodes and Workers one at a time.
  5. Check data types. In Resource → Manage added data sources, click Edit on Services and make sure ServiceDate is a Date and UnitCost is a Number (or Currency). Do the same for IntakeDate and DischargeDate in Clients.
  6. First chart. Insert → Scorecard, place it on the page. In Setup: Data source = Services, Metric = Record Count.
  7. Rename the report (top-left) to Casework Practice. It saves automatically.
Stuck? Try this
  • Can't see your spreadsheet in Looker Studio: it must be a Google Sheet, not an .xlsx sitting in Drive. Use File → Save as Google Sheets first.
  • Scorecard shows 13.4K: select it → Style → turn off Compact numbers.
  • UnitCost shows as text: in the data source editor, change its type to Number.
