1. Learn 15 min

XLOOKUP is like looking something up in a phone book:

=XLOOKUP( what to find,  where to look,       what to bring back,  if not found )
=XLOOKUP( "HV01",        ServiceCodes!A:A,    ServiceCodes!D:D,    "NOT FOUND" )
→ 85

"Find HV01 in column A of the price list, and bring back column D (UnitCost) from the same row." The fourth part is a safety net: if a code isn't in the price list you'll see NOT FOUND.

In Google Sheets you can look up every row at once by wrapping it in ARRAYFORMULA and giving it a whole column (D2:D) instead of one cell.

Read: XLOOKUP function (Google).

2. Do 40 min

  1. Open Casework Practice and go to the Services tab.
  2. Add a UnitCost column. In G1 type UnitCost. In G2: 
    =ARRAYFORMULA(IF(D2:D = "", , XLOOKUP(D2:D, ServiceCodes!A:A, ServiceCodes!D:D, "NOT FOUND")))
  3. Format as money. Click the G column letter → Format → Number → Currency.
  4. Add a Category column in H1/H2, using the same pattern but bringing back ServiceCodes!C:C.
  5. Check for failures. Data → Create a filter → UnitCost filter → Filter by values. There should be no NOT FOUND. Remove the filter.
  6. Grand total. In an empty cell to the right (e.g. K1) type =SUM(G2:G).
  7. Count the paid services. In K2 type: 
    =COUNTIF(G2:G, ">0")
Stuck? Try this
  • #REF! or #N/A: check the tab name is exactly ServiceCodes.
  • Lots of NOT FOUND: your codes still have spaces or lower case. Redo Week 3, or use the catch-up file services_clean.csv.
  • "Array result was not expanded": something is typed in the column below G2. Clear it.
  • Total is much higher than expected: duplicates are probably still in your data (Week 3, step 5).
