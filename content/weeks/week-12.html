Why this matters: managers always ask "compared to when?" Is spending going up? How long do clients usually stay with us? Time is the dimension behind most real questions.

This week's checklist

  • Group services by month
  • Build a monthly spend line chart
  • Calculate average length of stay
  • Answer all three checkpoints

1. Learn 15 min

  • To chart by month, every service needs a Month label. That's a calculated column, because you group by it.
  • Length of stay = days between IntakeDate and DischargeDate. Only discharged clients have one; active clients are excluded.
  • Professionals usually add a separate Date table (one row per day) for advanced time comparisons like "same month last year". That's this week's stretch.

Read: FORMAT, DATEDIFF, and optionally Date tables guidance.

2. Do 45 min

  1. Add a Month column. Select the Services table → New column: 
    Month = FORMAT(Services[ServiceDate], "yyyy-MM")
    You get labels like 2026-03. Because they're year-first, they sort correctly as text.
  2. Monthly trend. In the report, add a Line chart: X-axis = Services[Month], Y-axis = Total Spend. If the months are out of order: click the visual's … (More options) → Sort axis → Month, then Sort ascending.
  3. Find the numbers. Hover over the points to read each month's value. Or add a Table visual with Month and Total Spend and sort by Total Spend.
  4. Length of stay measure. Select the Clients table → New measure: 
    Avg Length of Stay (days) =
AVERAGEX(
    FILTER(Clients, NOT ISBLANK(Clients[DischargeDate])),
    DATEDIFF(Clients[IntakeDate], Clients[DischargeDate], DAY)
)
    In English: "Take only discharged clients. For each, count the days from intake to discharge. Average them." Put it on a card, formatted to 1 decimal place.
  5. Try it by program: a Table visual with Clients[Program] and Avg Length of Stay (days). Save.

3. Checkpoint 5 min

Which month had the highest total spend? (format: YYYY-MM)

Total spend in March 2026?

Average length of stay for discharged clients, in days (1 decimal)?

Stuck? Try this
  • Month shows things like 2026-00 or times: use capital MM for months (lowercase mm can mean minutes).
  • ServiceDate isn't a date: in Table view, select the column and set Data type to Date.
  • DATEDIFF error: check IntakeDate and DischargeDate are both Date type.
  • Length of stay is a huge negative number? The FILTER isn't excluding blank discharge dates, so active clients are being counted with an "empty" date. Check the NOT ISBLANK line.

Stretch (optional, 20 min)

Build a proper date table. New table:

Date = ADDCOLUMNS(
    CALENDAR(DATE(2025, 4, 1), DATE(2026, 9, 30)),
    "Month", FORMAT([Date], "yyyy-MM"),
    "Year", YEAR([Date])
)

Create a relationship from Date[Date] to Services[ServiceDate], then rebuild the line chart using Date[Month]. This is the professional pattern you'll see in workplace reports.

Try different date groupings on the same time series chart: click the calendar icon on ServiceDate and switch between Year Quarter, Year Week and Year. Then add a Date range control (Insert → Date range control) so viewers can pick their own period.
