Why this matters: "How many active clients do we have in Housing?" is a filter question. Most everyday questions can be answered in seconds once your data is set up as a proper table.

This week's checklist

  • Set up all four tables (named Excel Tables, or named tabs with filters in Sheets)
  • Sort and filter the Clients table
  • Answer both checkpoints

1. Learn 15 min

Right now your data is just cells. An Excel Table is a range Excel knows is one dataset. That gives you:

  • A name (e.g. Clients) you can use in formulas: Clients[Program] means "the Program column of the Clients table". That's far easier to read than D2:D301.
  • Filter and sort buttons on every header.
  • Automatic growth: add a row or column and formulas extend themselves.

Read: Overview of Excel tables (Microsoft, 5 min).

2. Do 40 min

  1. Make the Clients sheet a Table. Click any cell in the data, press ⌘ + T, make sure My table has headers is ticked, then click OK.
  2. Name it. With a cell in the table selected, go to the Table tab on the ribbon. In the Table Name box on the far left, type Clients and press Enter.
  3. Repeat for the other sheets. Name the tables exactly Services, ServiceCodes and Workers. These names are used in formulas later, so spelling matters.
  4. Sort. In Clients, click the arrow on IntakeDate → Ascending. The oldest intake is now at the top. Sort by ClientID ascending again to put things back.
  5. Filter by one value. Click the arrow on Program, untick (Select All), tick Housing Support. Now click the ClientID column header letter (column A) and read Count in the status bar at the bottom right. Subtract 1 for the header.
  6. Clear the filter (Program arrow → Clear Filter).
  7. Find active clients. A blank DischargeDate means the client is still active. Click the arrow on DischargeDate, untick (Select All), scroll to the bottom and tick (Blanks). Count the ClientIDs the same way.
  8. Clear all filters and save.

3. Checkpoint 5 min

How many clients are in the Housing Support program?

How many clients are still active (no discharge date)?

Stuck? Try this
  • No Table tab? Click inside the table first. The tab only appears when a table cell is selected.
  • Count looks too big? Make sure the filter is applied (the header arrow shows a funnel icon), and remember to subtract 1 for the header.
  • "(Blanks)" not in the list? Scroll to the very bottom of the filter list.

Stretch (optional, 15 min)

Filter for clients who are both in Mental Health and in the North region and still active. Filters stack: each one narrows the last. How many are there?
