Why this matters: in Week 3 you cleaned the data by hand. Next month you'd have to do it all again. Power Query records each cleaning step as a recipe. When a new export arrives you click Refresh and the recipe runs. It's also built into Power BI, so everything you learn here carries straight over.

Needs: Excel for Mac with Microsoft 365, version 16.69 or newer (see toolkit). Look for Data → Get Data (Power Query). Only have Excel for the web? Read along this week and next, then do the same steps in Power BI's Power Query editor in Week 9.

1. Learn 15 min

Power Query has three ideas:

  1. Source: where the data comes from (a file, a folder, a database).
  2. Applied Steps: the list on the right of the editor. Every click you make (trim, remove duplicates, filter) is saved as a step. Click any step to see the data as it was at that point.
  3. Load: send the finished result to a sheet. The original file is never changed.

Read: Import and shape data in Excel for Mac.

2. Do 50 min

  1. Start fresh. Create a new blank workbook and save it as Casework PQ.xlsx in your Data Course folder.
  2. Connect to the file. Data → Get Data (Power Query) → Text/CSV → browse to services_raw.csv → Next. You'll see a preview. Click Transform Data (not Load) to open the Power Query Editor.
  3. Look at Applied Steps. Power Query already added Source, Promoted Headers and Changed Type. Check that ServiceCode's column icon is ABC (text).
  4. Rule 1: trim and upper case. Click the ServiceCode header to select it. Transform → Format → Trim. Then Transform → Format → UPPERCASE. Two new steps appear.
  5. Rule 2: remove duplicates. Select all columns: click the first column header, then Shift-click the last. Home → Remove Rows → Remove Duplicates.
  6. Rule 3: remove blank codes. Click the filter arrow on ServiceCode. Untick the empty entry at the top of the list (it may show as (blank) or as an empty line) → OK.
    Can't find it? Use the arrow → Text Filters → Does Not Equal, leave the value box empty → OK.
  7. Name the query. In the Query Settings pane, change the name to Services.
  8. Load it. Home → Close & Load. A new sheet appears with a green table, and the Queries pane shows how many rows loaded.
  9. Count distinct codes. In an empty cell beside the table type =COUNTA(UNIQUE(Services[ServiceCode])).
  10. Test the magic. Go to Data → Refresh All. Same result in a second, with no manual steps. Save.

Stuck? Try this
  • No "Get Data (Power Query)" on the Data tab: update Excel (Help → Check for Updates). If it's still missing, your version doesn't support it. Skip to Week 9 and do these steps in Power BI instead.
  • 13,449 rows: the blank-code filter didn't apply. Check Applied Steps for a Filtered Rows step.
  • More than 14 distinct codes: the Trim or UPPERCASE step was applied to the wrong column. Click each step in Applied Steps to check.
  • Made a wrong step? Click the ✕ next to it in Applied Steps to delete it. Nothing is permanent here.

Stretch (optional, 15 min)

In the Power Query Editor, open View → Advanced Editor. That's the recipe written out in Power Query's language (called "M"). You don't need to write M, but try to match each line to a step you clicked.
