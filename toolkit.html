2. Power BI on a Mac (Weeks 9–16, Excel & Power BI path)

Path A (recommended): Power BI in your web browser

Cost: free (the "Power BI (free)" licence). Setup time: 10 minutes.

  • Go to app.powerbi.com and sign in. You need a work or school email (Microsoft blocks Gmail, Outlook.com and other personal addresses).
  • You can upload Excel files, build reports, create relationships and write measures in My workspace. You just can't share reports with other people on the free licence. That's fine for learning. What free users can do.
  • If your employer already uses Power BI, your work account probably has access already. Check with IT before uploading anything to a work account; the practice data here is fictional, so it's safe.

Path B: Power BI Desktop in a free Windows virtual machine

Cost: free (UTM + unactivated Windows). Setup time: 1–2 hours. Needs: Apple-silicon Mac (M1 or newer), 16 GB memory recommended, 64 GB free disk.

  • Install UTM (free) and the Windows 11 for Arm disk image from Microsoft. Unactivated Windows works for learning; it just shows a watermark.
  • Inside Windows, install Power BI Desktop from the Microsoft Store (free).
  • This is the most complete experience, the same app most workplaces use. Power BI Desktop isn't officially supported on Arm Windows, but it generally runs. If it misbehaves, use Path A.
  • Prefer smoother and paid? Parallels Desktop does the same job with less setup.

If neither Power BI option works for you, use the Google Sheets & Looker Studio path instead.

3. Google Sheets & Looker Studio (all weeks, Google path)

Cost: free with any Google account (Gmail is fine). Setup time: 5 minutes. Works in any browser on a Mac.

  • Google Sheets for Weeks 1–8. It has the same functions the course uses: XLOOKUP, SUMIFS, UNIQUE, pivot tables and slicers. Instead of Power Query, Weeks 7–8 build a cleaning "recipe" with one formula.
  • Looker Studio for Weeks 9–16. It connects live to your Google Sheet, so the dashboard updates when the Sheet does. Relationships become blends, measures become calculated fields, and slicers become controls.
  • Sharing is free, too.

4. Do I ever need to pay?

  • To learn: no, on either path.
  • To share reports with coworkers in Power BI: everyone involved needs Power BI Pro (about US $14 per user per month), or the organization needs a Premium/Fabric capacity. At a job this is the employer's cost, not yours. There's usually a free 60-day Pro trial.
  • Optional certificate: Microsoft's PL-300 Power BI Data Analyst exam is paid. The learning paths for it are free. See Week 16.

5. Free learning resources (used throughout)

  • Microsoft Learn: Power BI training: free, official, self-paced modules.
  • Excel help & learning: official how-to articles for every function used here.
  • DAX function reference: look up any Power BI formula.
