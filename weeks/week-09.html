Week 9 of 16 · Phase 3 · Dashboards

Set up Power BI or Looker Studio

Power BI Looker Studio ⏱ About 75 min

Get your dashboard tool running, load the four tables and find your way around.

Show steps for:

Why this matters: Spreadsheets got you far, but they start to strain when there are many tables, many questions and many people asking. Dashboard tools like Power BI and Looker Studio are built for exactly what your colleagues did: take raw tables, connect them, and build reports anyone can click through.

This week's checklist

1. Learn 15 min

Power BI has three parts you'll use constantly:

  • Data pane (right side): your tables and their columns.
  • Visualizations pane: chart types. Click one, then drag columns into its boxes, just like a PivotTable.
  • Views: Report (the canvas), Table/Data (see the rows) and Model (see how tables connect, next week).

Read: Microsoft Learn's free module Get started building with Power BI. Do just the first two or three units this week.

2. Do 50 min

Download powerbi-starter.xlsx first. It holds the four clean tables, each as a named table. Then follow your path from the toolkit:

Path A: Power BI in the browser

  1. Go to app.powerbi.com and sign in with your work or school email. If asked, start the free account.
  2. In the left menu, open My workspace.
  3. Click + New item → Semantic model → Excel (or Upload / Get data, as the wording changes) → choose powerbi-starter.xlsx from your Mac. Select all four tables if asked.
  4. When it finishes, open the new semantic model. You'll see buttons like Open data model (to see tables and relationships) and Create a report → Start from scratch (to build visuals). Try both.
  5. In the report editor, click the Card visual, then tick ServiceID under the Services table in the Data pane. The card shows Count of ServiceID.
  6. Save the report as Casework Practice (File → Save).

Path B: Power BI Desktop (Windows VM)

  1. Open Power BI Desktop → Home → Get data → Excel workbook → choose powerbi-starter.xlsx (copy it into the VM, or use a shared folder).
  2. In the Navigator, tick the four tables (Services, Clients, ServiceCodes, Workers) → Load.
  3. Click the three icons on the left edge to switch between Report, Table and Model views.
  4. In Report view, click the Card visual, then tick ServiceID in the Services table. The card shows Count of ServiceID.
  5. File → Save as Casework Practice.pbix.

Both paths: open the Table/Data view, click each table and scroll. It's the same data you know from Excel.

1. Learn 15 min

Looker Studio is Google's free dashboard tool. It reads directly from Google Sheets, so when the Sheet changes, the dashboard updates. Three parts you'll use constantly:

  • Data sources: each tab of your Sheet becomes a data source (a table).
  • Charts and controls: add from the Insert menu, then choose fields in the Setup panel on the right, like filling a pivot table.
  • Edit vs. View mode: you build in Edit; others click around in View.

Read: Create a report from Google Sheets (Google).

2. Do 50 min

  1. Put the clean data in one Google Sheet. Upload powerbi-starter.xlsx to Google Drive (New → File upload). Double-click it, then File → Save as Google Sheets. Rename it Casework Data. It has tabs for Services, Clients, ServiceCodes and Workers (plus two for the Caseworks track).
  2. Add a UnitCost column to Services (Looker Studio works best when the cost is already on each row). On the Services tab, in G1 type UnitCost and in G2: 
    =ARRAYFORMULA(IF(D2:D = "", , XLOOKUP(D2:D, ServiceCodes!A:A, ServiceCodes!D:D)))
    Exactly what you did in Week 4.
  3. Create a report. Go to lookerstudio.google.com → Create → Report → Google Sheets → Casework Data → worksheet Services → keep Use first row as headers ticked → Add.
  4. Add the other tabs as data sources. Resource → Manage added data sources → Add a data source → Google Sheets. Add Clients, ServiceCodes and Workers one at a time.
  5. Check data types. In Resource → Manage added data sources, click Edit on Services and make sure ServiceDate is a Date and UnitCost is a Number (or Currency). Do the same for IntakeDate and DischargeDate in Clients.
  6. First chart. Insert → Scorecard, place it on the page. In Setup: Data source = Services, Metric = Record Count.
  7. Rename the report (top-left) to Casework Practice. It saves automatically.

3. Checkpoint 5 min

What number does your Count of ServiceID card show?

Stuck? Try this
  • "You can't sign up with this email" (Path A): Power BI requires a work or school email. Try Path B, or switch to the Google Sheets & Looker Studio steps at the top of this page.
  • Card shows a big number like 1.3K? That's 13,4xx shortened. Select the card → Format visual → Callout value → Display units → None.
  • Card shows "First ServiceID" instead of a count: click the dropdown on ServiceID in the visual's field well → Count.
Stuck? Try this
  • Can't see your spreadsheet in Looker Studio: it must be a Google Sheet, not an .xlsx sitting in Drive. Use File → Save as Google Sheets first.
  • Scorecard shows 13.4K: select it → Style → turn off Compact numbers.
  • UnitCost shows as text: in the data source editor, change its type to Number.

Stretch (optional, 15 min)

Add a second card for the number of clients (Clients[ClientID], count). Then click the Table visual and drag in ServiceCodes[Description] and ServiceCodes[UnitCost]. That's your price list, inside Power BI.

Add a second scorecard for the number of clients (Clients data source, ClientID as Count Distinct). Then add a table on the ServiceCodes data source with Description and UnitCost. That's your price list, inside Looker Studio.
