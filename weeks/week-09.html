Week 9 of 16 · Phase 3 · Power BI

Get Power BI running on your Mac

Power BI ⏱ About 75 min

Choose your Power BI path, load the four tables and find your way around.

Why this matters: Excel got you far, but it starts to strain when there are many tables, many questions and many people asking. Power BI is built for exactly what your colleagues did: take raw tables, connect them, and build reports anyone can click through.

This week's checklist

1. Learn 15 min

Power BI has three parts you'll use constantly:

  • Data pane (right side): your tables and their columns.
  • Visualizations pane: chart types. Click one, then drag columns into its boxes, just like a PivotTable.
  • Views: Report (the canvas), Table/Data (see the rows) and Model (see how tables connect, next week).

Read: Microsoft Learn's free module Get started building with Power BI. Do just the first two or three units this week.

2. Do 50 min

Download powerbi-starter.xlsx first. It holds the four clean tables, each as a named table. Then follow your path from the toolkit:

Path A: Power BI in the browser

  1. Go to app.powerbi.com and sign in with your work or school email. If asked, start the free account.
  2. In the left menu, open My workspace.
  3. Click + New item → Semantic model → Excel (or Upload / Get data, as the wording changes) → choose powerbi-starter.xlsx from your Mac. Select all four tables if asked.
  4. When it finishes, open the new semantic model. You'll see buttons like Open data model (to see tables and relationships) and Create a report → Start from scratch (to build visuals). Try both.
  5. In the report editor, click the Card visual, then tick ServiceID under the Services table in the Data pane. The card shows Count of ServiceID.
  6. Save the report as Casework Practice (File → Save).

Path B: Power BI Desktop (Windows VM)

  1. Open Power BI Desktop → Home → Get data → Excel workbook → choose powerbi-starter.xlsx (copy it into the VM, or use a shared folder).
  2. In the Navigator, tick the four tables (Services, Clients, ServiceCodes, Workers) → Load.
  3. Click the three icons on the left edge to switch between Report, Table and Model views.
  4. In Report view, click the Card visual, then tick ServiceID in the Services table. The card shows Count of ServiceID.
  5. File → Save as Casework Practice.pbix.

Both paths: open the Table/Data view, click each table and scroll. It's the same data you know from Excel.

3. Checkpoint 5 min

What number does your Count of ServiceID card show?

Stuck? Try this
  • "You can't sign up with this email" (Path A): Power BI requires a work or school email. Try Path B, or use Path C (Looker Studio) from the toolkit.
  • Card shows a big number like 1.3K? That's 13,4xx shortened. Select the card → Format visual → Callout value → Display units → None.
  • Card shows "First ServiceID" instead of a count: click the dropdown on ServiceID in the visual's field well → Count.

Stretch (optional, 15 min)

Add a second card for the number of clients (Clients[ClientID], count). Then click the Table visual and drag in ServiceCodes[Description] and ServiceCodes[UnitCost]. That's your price list, inside Power BI.

Week 9 is done. Take a breath; next week builds on this.
