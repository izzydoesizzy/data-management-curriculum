Project 3: Casework Cost Dashboard

Power BI Looker Studio ⏱ About 2 × 60 min

Build a one-page dashboard to an exact spec, then use it to answer questions.

Show steps for:

Project 3: this is the report you wished existed when you were doing casework. One page that answers where is the money going, for whom, and how is it changing, and that anyone can filter by region, program or role with a click. Split it over two sessions.

Project spec (exact parameters)

Page name: Cost Dashboard · Title text box: "Casework Cost Dashboard · Apr 2025 to Aug 2026"

Ten visuals sounds like a lot, but slicers and cards are small. Everything should fit on one screen without scrolling.

This week's checklist

Session 1 60 min

  1. Add a new page (the + at the bottom). Double-click its tab and rename it Cost Dashboard.
  2. Title: Insert → Text box. Type the title, size 20, bold.
  3. Slicers: click the Slicer visual, add Clients[Region]. In Format → Slicer settings → Style choose Dropdown. Repeat for Program and Role. Line them up along the top.
  4. Cards: four Card visuals in a row, one per measure. Use View → Gridlines / Snap to grid (Desktop) to align them.
  5. Spend by Program and Monthly Spend as in the spec. Turn on data labels for the bar chart (Format → Data labels → On). Save.

Session 2 60 min

  1. Spend by Category bar chart, as in the spec.
  2. Client Detail table: add the five fields, then click the Total Spend header to sort descending.
  3. Tidy up: same width for the two charts in each row, consistent gaps, all titles in the same size. Rename the measure fields in the visuals if needed (double-click a field in the field well).
  4. The 5-second test: show it to someone (or imagine your old supervisor). In 5 seconds, can they say what the agency spent and where most of it goes? If not, what's in the way?
  5. Use it. Set the slicers to answer the checkpoints below. Then clear the slicers. Save.

Looker Studio version of the spec: same layout. Slicers = drop-down list controls, cards = scorecards, line chart = time series with ServiceDate as Year Month. Use the Casework Model blend for every chart and control, so the filters affect everything.

Session 1 60 min

  1. Add a new page (Page → New page). Rename it Cost Dashboard (Page → Manage pages).
  2. Title: Insert → Text. Type the title, size 20, bold.
  3. Controls: Insert → Drop-down list, data source Casework Model, Control field = Region. Repeat for Program and Role. Line them up along the top.
  4. Scorecards: four in a row, for Total Spend, Clients Served, Avg Spend per Client and Total Services (copy them from Week 11). Use Arrange → Align to line them up.
  5. Spend by Program (bar chart, sorted descending, data labels on under Style) and Monthly Spend (time series).

Session 2 60 min

  1. Spend by Category bar chart, sorted descending.
  2. Client Detail table: Dimensions ClientID, Program, Region; Metrics Total Services, Total Spend; sort by Total Spend descending.
  3. Tidy up: same widths, consistent gaps, all titles the same size (Style → Chart title).
  4. The 5-second test: click View (top-right) and show it to someone. In 5 seconds, can they say what the agency spent and where most of it goes?
  5. Use it. In View mode, set the controls to answer the checkpoints below, then reset them.

Checkpoint 5 min

Set Program = Youth Services and Region = Central. What is Total Spend?

Clear those, then set Role = Community Help Worker. What is Total Spend for services delivered by Community Help Workers?

Stuck? Try this
  • The Role slicer doesn't change anything: the Workers→Services relationship is missing (Week 10).
  • Client Detail table shows one row with everything: use Clients[ClientID] as a plain column (not "Count of").
  • Cards show 846.44K: select the card → Format → Callout value → Display units → None.
Stuck? Try this
  • A control doesn't filter a chart: controls only filter charts that use the same data source. Make sure every chart uses the Casework Model blend.
  • Role control is empty: the Workers join (Week 10) is missing Role as a dimension. Edit the blend and add it.
  • Scorecards show 846.4K: Style → turn off Compact numbers.
  • Want drill-through? Looker Studio uses cross-filtering instead: in View mode, click a program's bar and every other chart filters to it. Click again to clear. For a client profile page, add a ClientID drop-down control on a second page.

Using CaseWORKS? This dashboard is the same shape as one built on real CaseWORKS service events. After the capstone, try the waitlist, no-show and caseload projects on the Caseworks page.

Stretch (optional, 30 min): client drill-through

Make a second page called Client Profile. Drag Clients[ClientID] into its Drill through box (in the Visualizations pane, under Build). Add cards for Total Spend and Total Services, and a table of that client's services (ServiceDate, ServiceCodes[Description], Workers[Name], ServiceCodes[UnitCost]). Back on the dashboard, right-click a client in Client Detail → Drill through → Client Profile. Read: Set up drill-through.
