Week 1 of 16 · Phase 1 · Excel foundations

Set up and meet your data

Excel ⏱ About 60 min

Get your free tools working, download the practice data and learn what a good raw table looks like.

Why this matters: every report you were frustrated by at work started as rows of raw data. Once you can hold the raw data yourself, the report is just a set of questions you ask it. This week is about getting comfortable just looking at raw data.

This week's checklist

1. Learn 15 min

Raw data vs. reports

A report is a summary: "Housing Support spent $358K this year." Raw data is the list of every single event behind it: each home visit, each rent supplement, each phone call. You can always build a report from raw data, but you can never get the raw data back from a report. That's why colleagues pulled raw data into Power BI: it let them ask their own questions.

What a good raw table looks like ("tidy data")

  • One row = one thing. In our services file, one row = one service, delivered to one client, on one day.
  • One column = one kind of fact. A date column only has dates. A cost column only has numbers.
  • One header row, at the top. No titles above it, no merged cells, no subtotal rows sprinkled in.
  • An ID column that connects to other tables (ClientID, ServiceCode, WorkerID).

Open the practice data page and look at the diagram of how the tables connect. Keep it handy; we'll use it all course.

2. Do 40 min

  1. Download the data. On the practice data page, click Download everything. Double-click the .zip in your Downloads folder to unzip it. Move the folder to Documents/Data Course.
  2. Open the services file. In Excel: File → Open, then pick services_raw.csv.
  3. Save it as a real workbook. File → Save As, name it Casework Practice, and set File Format to Excel Workbook (.xlsx). CSV files can't hold multiple sheets or formulas, so always convert. Right-click the sheet tab at the bottom and rename it Services.
  4. Add the other three tables as sheets. Open clients.csv. Right-click its sheet tab → Move or Copy… → under To book choose Casework Practice.xlsx → tick Create a copy → OK. Rename the tab Clients. Do the same for service_codes.csv (tab name ServiceCodes) and workers.csv (tab name Workers).
  5. Freeze the header row on each sheet so it stays visible as you scroll: View → Freeze Top Row.
  6. Get around fast. On the Services sheet, click cell A1, then press ⌘ + ↓ to jump to the last row. ⌘ + ↑ jumps back up. Look at the row number on the left of the last row.
  7. Explore. Scroll through each sheet for 5 minutes. Find a client in Clients, then find a few of their services in Services. Look up what their service codes mean in ServiceCodes.
  8. Save (⌘ + S).

3. Checkpoint 5 min

Stuck? Try this
  • Row count off by one? The last row number includes the header row in row 1. Subtract 1.
  • Another way: click the column letter A to select the whole column, then look at the bottom-right of the Excel window. Count shows how many filled cells there are (including the header). If you don't see Count, right-click the status bar and tick it.
  • The file opened in Numbers instead of Excel? Right-click the file → Open With → Microsoft Excel.

Stretch (optional, 15 min)

Write down three questions you wished your old reports could answer. Keep the list. In Week 16 you'll turn them into a real report plan.
