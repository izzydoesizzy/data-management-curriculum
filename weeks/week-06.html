Week 6 of 16 · Phase 1 · Excel foundations

Project 2: PivotTables

Excel ⏱ About 90 min

Summarize 13,000 rows in seconds by program, category and client, with clickable filters.

Project 2: last week took five formulas per question. A PivotTable answers "spend by program", "spend by category", "top 10 clients" by dragging and dropping. This is the closest thing in Excel to the reports colleagues were building in Power BI.

Project spec (exact parameters)

Deliverable: a sheet called Pivot - Program and a sheet called Pivot - Top Clients.

  • Pivot - Program: Rows = Program, Columns = Category, Values = Sum of UnitCost (currency, no decimals), plus a Region slicer.
  • Pivot - Top Clients: Rows = ClientID, Values = Sum of UnitCost, sorted largest to smallest, filtered to the top 10.

This week's checklist

1. Learn 15 min

A PivotTable has four boxes you drag fields into:

  • Rows: what you want one line per (e.g. Program)
  • Columns: what to split across the top (e.g. Category)
  • Values: the number to calculate (e.g. Sum of UnitCost)
  • Filters: what to narrow the whole thing by

A slicer is a set of clickable filter buttons, the same idea as the slicers in Power BI.

Read: Create a PivotTable.

2. Do 60 min

  1. Add Program to Services (skip if you did the Week 4 stretch). In the first empty header cell of Services type Program, then in the row below: 
    =XLOOKUP([@ClientID], Clients[ClientID], Clients[Program])
  2. Add Region the same way, returning Clients[Region].
  3. Insert the PivotTable. Click inside the Services table → Insert → PivotTable → New Worksheet → OK. Rename the new sheet Pivot - Program.
  4. In the PivotTable Fields panel, drag Program to Rows, Category to Columns and UnitCost to Values. It should say Sum of UnitCost (if it says Count, click it → Field Settings → Sum).
  5. Format numbers. Click Sum of UnitCost in Values → Field Settings → Number Format → Currency, 0 decimal places.
  6. Add a slicer. Click in the PivotTable → PivotTable Analyze tab → Insert Slicer → tick Region. Click a region to filter and watch the numbers change. Clear the slicer (the funnel-with-X icon) when done.
  7. Second PivotTable. From the Services table again, Insert → PivotTable → New Worksheet. Rename the sheet Pivot - Top Clients. Rows = ClientID, Values = Sum of UnitCost.
  8. Sort. Right-click any number → Sort → Sort Largest to Smallest.
  9. Top 10. Click the Row Labels dropdown → Value Filters → Top 10… → OK. Save.

3. Checkpoint 5 min

Which program has the highest total spend?

How much did that program spend in total?

Which client (ClientID) has the highest total spend?

Total spend in the Financial Assistance category (all programs)?

Stuck? Try this
  • Fields panel disappeared? Click inside the PivotTable. To reopen it: PivotTable Analyze → Field List.
  • Numbers look wrong after cleaning more data? PivotTables don't update by themselves. Right-click → Refresh.
  • Grand totals don't match Week 4? Make sure the slicer isn't filtering anything.

Stretch (optional, 20 min)

Make a third PivotTable: Rows = Region, Values = Sum of UnitCost. Which region spends the most? Now the harder question: is that because it has more clients, or more spend per client? A regular PivotTable can't easily count unique clients. That's one of the reasons Power BI exists, and you'll answer it properly in Week 15.
