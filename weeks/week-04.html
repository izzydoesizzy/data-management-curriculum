Week 4 of 16 · Phase 1 · Spreadsheet foundations

Lookups: attach the dollar amounts

Excel Google Sheets ⏱ About 60 min

Use XLOOKUP to bring each service's cost into your services table. This is where the money appears.

Show steps for:

Why this matters: this is the exact problem you described. The services table says what happened (code HV01), but the cost lives in a separate price list. A lookup connects them. After today, every service row has a dollar figure.

This week's checklist

1. Learn 15 min

XLOOKUP is like looking something up in a phone book:

=XLOOKUP( what to find,  where to look,  what to bring back,  if not found )
=XLOOKUP( "HV01",        ServiceCodes[ServiceCode],  ServiceCodes[UnitCost],  "NOT FOUND" )
→ 85

"Find HV01 in the ServiceCode column of the price list, and bring back the UnitCost from the same row." The fourth part is a safety net: if a code isn't in the price list you'll see NOT FOUND instead of a confusing error.

Read: XLOOKUP function. You may have heard of VLOOKUP; XLOOKUP is its modern, easier replacement.

2. Do 40 min

  1. Open Casework Practice.xlsx and go to the Services sheet.
  2. Add a UnitCost column. In the first empty header cell (G1) type UnitCost. In G2 type: 
    =XLOOKUP([@ServiceCode], ServiceCodes[ServiceCode], ServiceCodes[UnitCost], "NOT FOUND")
    Press Enter. It fills all the way down.
  3. Format as money. Select the UnitCost column data → Home → number format dropdown → Currency.
  4. Add a Category column in H1, using the same pattern but bringing back ServiceCodes[Category].
  5. Check for failures. Click the UnitCost filter arrow and scroll the list. There should be no NOT FOUND. If there is, that code wasn't cleaned (go back to Week 3, step 3).
  6. Grand total. Click in the table → Table tab → tick Total Row. A total row appears at the bottom. Click the total cell under UnitCost and choose Sum from its dropdown.
  7. Count the paid services. In any empty cell to the right of the table (e.g. K2) type: 
    =COUNTIF(Services[UnitCost], ">0")
  8. Save.

1. Learn 15 min

XLOOKUP is like looking something up in a phone book:

=XLOOKUP( what to find,  where to look,       what to bring back,  if not found )
=XLOOKUP( "HV01",        ServiceCodes!A:A,    ServiceCodes!D:D,    "NOT FOUND" )
→ 85

"Find HV01 in column A of the price list, and bring back column D (UnitCost) from the same row." The fourth part is a safety net: if a code isn't in the price list you'll see NOT FOUND.

In Google Sheets you can look up every row at once by wrapping it in ARRAYFORMULA and giving it a whole column (D2:D) instead of one cell.

Read: XLOOKUP function (Google).

2. Do 40 min

  1. Open Casework Practice and go to the Services tab.
  2. Add a UnitCost column. In G1 type UnitCost. In G2: 
    =ARRAYFORMULA(IF(D2:D = "", , XLOOKUP(D2:D, ServiceCodes!A:A, ServiceCodes!D:D, "NOT FOUND")))
  3. Format as money. Click the G column letter → Format → Number → Currency.
  4. Add a Category column in H1/H2, using the same pattern but bringing back ServiceCodes!C:C.
  5. Check for failures. Data → Create a filter → UnitCost filter → Filter by values. There should be no NOT FOUND. Remove the filter.
  6. Grand total. In an empty cell to the right (e.g. K1) type =SUM(G2:G).
  7. Count the paid services. In K2 type: 
    =COUNTIF(G2:G, ">0")

Stuck? Try this
  • #NAME? error: a table name is misspelled. Check it's exactly ServiceCodes (Week 2, step 3) or your Excel is too old for XLOOKUP. Excel for the web always has it.
  • Lots of NOT FOUND: your codes still have spaces or lower case. Redo Week 3 steps 2–5, or use the catch-up file services_clean.csv.
  • Total is much higher than expected: you probably still have duplicates (Week 3, step 6).
  • Total includes the Total Row itself? If you used the status bar, don't select the total row.
Stuck? Try this
  • #REF! or #N/A: check the tab name is exactly ServiceCodes.
  • Lots of NOT FOUND: your codes still have spaces or lower case. Redo Week 3, or use the catch-up file services_clean.csv.
  • "Array result was not expanded": something is typed in the column below G2. Clear it.
  • Total is much higher than expected: duplicates are probably still in your data (Week 3, step 5).
