Week 7 of 16 · Phase 2 · Repeatable cleaning

A recipe for cleaning

Power Query Sheets formulas ⏱ About 75 min

Redo Week 3's cleaning as recorded steps you never have to repeat by hand.

Show steps for:

Why this matters: in Week 3 you cleaned the data by hand. Next month you'd have to do it all again. This week you turn your cleaning into a recipe: with Power Query (Excel & Power BI) or one formula (Google Sheets). When a new export arrives, the recipe reruns and you're done.

Needs: Excel for Mac with Microsoft 365, version 16.69 or newer (see toolkit). Look for Data → Get Data (Power Query). Only have Excel for the web? Switch to the Google Sheets steps above for Weeks 7–8, or read along and do these steps in Power BI's Power Query editor in Week 9.

This week's checklist

1. Learn 15 min

Power Query has three ideas:

  1. Source: where the data comes from (a file, a folder, a database).
  2. Applied Steps: the list on the right of the editor. Every click you make (trim, remove duplicates, filter) is saved as a step. Click any step to see the data as it was at that point.
  3. Load: send the finished result to a sheet. The original file is never changed.

Read: Import and shape data in Excel for Mac.

2. Do 50 min

  1. Start fresh. Create a new blank workbook and save it as Casework PQ.xlsx in your Data Course folder.
  2. Connect to the file. Data → Get Data (Power Query) → Text/CSV → browse to services_raw.csv → Next. You'll see a preview. Click Transform Data (not Load) to open the Power Query Editor.
  3. Look at Applied Steps. Power Query already added Source, Promoted Headers and Changed Type. Check that ServiceCode's column icon is ABC (text).
  4. Rule 1: trim and upper case. Click the ServiceCode header to select it. Transform → Format → Trim. Then Transform → Format → UPPERCASE. Two new steps appear.
  5. Rule 2: remove duplicates. Select all columns: click the first column header, then Shift-click the last. Home → Remove Rows → Remove Duplicates.
  6. Rule 3: remove blank codes. Click the filter arrow on ServiceCode. Untick the empty entry at the top of the list (it may show as (blank) or as an empty line) → OK.
    Can't find it? Use the arrow → Text Filters → Does Not Equal, leave the value box empty → OK.
  7. Name the query. In the Query Settings pane, change the name to Services.
  8. Load it. Home → Close & Load. A new sheet appears with a green table, and the Queries pane shows how many rows loaded.
  9. Count distinct codes. In an empty cell beside the table type =COUNTA(UNIQUE(Services[ServiceCode])).
  10. Test the magic. Go to Data → Refresh All. Same result in a second, with no manual steps. Save.

1. Learn 15 min

Google Sheets doesn't have Power Query, but you can build the same idea, a cleaning recipe that reruns itself, with two tabs:

  1. Raw: where you paste each new export, untouched.
  2. Clean: one formula that reads Raw and applies all three cleaning rules. Paste new data into Raw and Clean updates instantly.

The formula uses a few building blocks:

PieceWhat it does
LET(name, value, …)Gives a piece of the formula a name so it's readable
CHOOSECOLS(raw, 4)Picks column 4 (ServiceCode) out of the raw table
UPPER(TRIM(…))Rule 1: tidy the codes
HSTACK(…)Glues columns back together side by side
FILTER(…, code <> "")Rule 3: drop rows with no code
UNIQUE(…)Rule 2: drop duplicate rows

Read: LET function (Google).

2. Do 50 min

  1. Start fresh. Create a new blank spreadsheet called Casework Recipe.
  2. Raw tab. File → Import → Upload → services_raw.csv → Replace current sheet. Rename the tab Raw. Don't edit anything on this tab, ever.
  3. Clean tab. Add a new tab called Clean. Copy the header row from Raw into row 1 (A1:F1).
  4. The recipe. In Clean!A2 paste: 
    =ARRAYFORMULA(LET(
  raw,  Raw!A2:F,
  code, UPPER(TRIM(CHOOSECOLS(raw, 4))),
  UNIQUE(FILTER(
    HSTACK(CHOOSECOLS(raw, 1, 2, 3), code, CHOOSECOLS(raw, 5, 6)),
    code <> ""))))
    The whole cleaned table appears.
  5. Count rows. In H1 type =COUNTA(A2:A).
  6. Count distinct codes. In H2 type =COUNTUNIQUE(D2:D).
  7. Test the magic. On the Raw tab, add a fake row at the bottom with code " hv01 ", then look at Clean: it appears as HV01. Delete the fake row again.

Stuck? Try this
  • No "Get Data (Power Query)" on the Data tab: update Excel (Help → Check for Updates). If it's still missing, your version doesn't support it. Skip to Week 9 and do these steps in Power BI instead.
  • 13,449 rows: the blank-code filter didn't apply. Check Applied Steps for a Filtered Rows step.
  • More than 14 distinct codes: the Trim or UPPERCASE step was applied to the wrong column. Click each step in Applied Steps to check.
  • Made a wrong step? Click the ✕ next to it in Applied Steps to delete it. Nothing is permanent here.
Stuck? Try this
  • Formula error about LET or CHOOSECOLS: check every bracket and comma. Copy the formula exactly from this page.
  • 13,449 rows: the code <> "" filter is missing.
  • More than 14 distinct codes: the UPPER(TRIM(...)) part isn't applied to column 4.
  • "Array result was not expanded": the Clean tab has stray data below A2. Clear it.

Stretch (optional, 15 min)

In the Power Query Editor, open View → Advanced Editor. That's the recipe written out in Power Query's language (called "M"). You don't need to write M, but try to match each line to a step you clicked.

Replace the Raw tab's pasted data with a live link. Once this site is published, in Raw!A1 type =IMPORTDATA("https://izzydoesizzy.github.io/data-management-curriculum/data/services_raw.csv"). Your Clean tab now updates straight from the source file. That's the Sheets version of "Refresh".
