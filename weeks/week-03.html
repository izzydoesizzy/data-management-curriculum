Cleaning messy exports

Excel ⏱ About 75 min

Fix the mess that real systems produce: stray spaces, inconsistent case, duplicates and blanks.

Why this matters: bad reports are often bad because of dirty data. If "HV01" and "hv01 " are counted as different services, or a visit was exported twice, every total is wrong. Cleaning is unglamorous, but it's the part that makes your numbers trustworthy.

This week's checklist

1. Learn 15 min

Our export has four problems, all very common in real systems:

ProblemExampleFix
Extra spaces"HV01 "TRIM() removes spaces at the start and end
Inconsistent case"hv01"UPPER() makes everything capitals
Duplicate rowsSame ServiceID twiceData → Remove Duplicates
Missing valuesBlank ServiceCodeFilter for blanks and delete those rows

Our three cleaning rules (used for every answer in this course):

  1. Service codes: trim spaces and convert to upper case.
  2. Remove exact duplicate rows.
  3. Remove rows with a blank service code.

Read: TRIM function and Remove duplicate values.

Before you start: make a backup. File → Save As → Casework Practice - before cleaning.xlsx, then reopen Casework Practice.xlsx. Professionals never clean the only copy.

2. Do 50 min

  1. See the mess. In the Services table, click the arrow on ServiceCode. You'll see a blank entry, plus codes that look identical but are listed twice (one has a hidden trailing space). Close the menu.
  2. Add a helper column. Click the first empty cell to the right of the header row (cell G1) and type CodeClean, then Enter. The table grows to include it.
  3. Write the cleaning formula. In G2 type: 
    =UPPER(TRIM([@ServiceCode]))
    Press Enter. The formula fills down all 13,567 rows automatically. [@ServiceCode] means "the ServiceCode in this row".
  4. Replace the original codes with the clean ones. Click the top edge of the CodeClean header (cursor becomes a ↓ arrow) to select the column's data, then press ⌘ + C. Select the ServiceCode column's data the same way, then Edit → Paste Special… → Values → OK.
  5. Delete the helper column. Right-click any cell in CodeClean → Delete → Table Columns.
  6. Remove duplicates. Click any cell in the table → Data tab → Remove Duplicates. Make sure all columns are ticked → OK. Excel tells you how many duplicates it removed. Write that number down.
  7. Remove blank codes. ServiceCode arrow → untick (Select All) → tick only (Blanks). Select all visible rows (click the first row number, then Shift-click the last), right-click → Delete Row. Then clear the filter.
  8. Count what's left. Click column A's letter and read Count (minus 1 for the header). Save.

3. Checkpoint 5 min

How many duplicate rows did Remove Duplicates remove?

How many service rows are left after all three cleaning rules?

Stuck? Try this
  • You have 13,449 rows: you removed duplicates but not the blank codes (step 7).
  • You have 13,530 rows: you removed blanks but not duplicates (step 6).
  • Remove Duplicates removed far more than ~100? Some columns were unticked, so Excel treated rows as duplicates when only some columns matched. Undo (⌘ + Z) and tick every column.
  • Formula shows as text? The cell was formatted as Text. Format the column as General and re-enter the formula.
  • Totally lost? No problem. Download services_clean.csv, which is the finished result. Paste it over your Services sheet and carry on next week.

Stretch (optional, 15 min)

Use the filter on ServiceCode again. How many distinct codes are there now? Compare with the 14 rows in the ServiceCodes table. They should match exactly. If they do, your data is ready for Week 4.
