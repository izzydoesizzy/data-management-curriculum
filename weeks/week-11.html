Measures: your first calculations

Power BI Looker Studio ⏱ About 75 min

Write the three measures every casework report needs: Total Spend, Clients Served and Avg Spend per Client.

Show steps for:

Why this matters: a measure is a reusable calculation, like "Total Spend", that automatically recalculates for whatever you're looking at: the whole agency on a card, per program in a chart, per client in a table. Write it once, use it everywhere.

This week's checklist

1. Learn 20 min

DAX is Power BI's formula language. Our most important measure:

Total Spend = SUMX( Services, RELATED( ServiceCodes[UnitCost] ) )

In plain English: "Go through the Services table row by row (SUMX). For each service, follow the relationship to the price list and fetch its UnitCost (RELATED). Add them all up." It's Week 4's XLOOKUP plus Week 5's SUM, done in one line, with no extra columns needed.

Read: SUMX, RELATED and DIVIDE in the DAX reference.

2. Do 45 min

  1. Create a measure. Path A: in the data model editor, select the Services table → New measure. Path B: in the Data pane, right-click Services → New measure. A formula bar appears at the top.
  2. Type each measure exactly, pressing Enter after each one (create a new measure each time): 
    Total Spend = SUMX(Services, RELATED(ServiceCodes[UnitCost]))

Total Services = COUNTROWS(Services)

Clients Served = DISTINCTCOUNT(Services[ClientID])

Avg Spend per Client = DIVIDE([Total Spend], [Clients Served])
  3. Format them. Select Total Spend in the Data pane → in Measure tools (or the properties pane) set Format to Currency, 2 decimals. Do the same for Avg Spend per Client. Set Total Services and Clients Served to Whole number.
  4. Cards. In the report, replace last week's cards with four cards, one per measure.
  5. Table by region. Add a Table visual with Clients[Region], Total Spend, Clients Served and Avg Spend per Client. One set of measures, five regions, all different values. That's filter context at work.
  6. Compare Total Spend with your Excel answer from Week 4. They should match exactly. Save.

1. Learn 20 min

In Looker Studio, a metric is a number that recalculates for whatever the chart shows: the whole agency on a scorecard, per program in a bar chart, per client in a table. You can create your own with calculated fields:

Total Spend          = SUM(UnitCost)
Total Services       = COUNT(ServiceID)
Clients Served       = COUNT_DISTINCT(ClientID)
Avg Spend per Client = SUM(UnitCost) / COUNT_DISTINCT(ClientID)

In plain English, Total Spend is "add up the cost of every service in view." Because you put UnitCost on each row in Week 9 (the same XLOOKUP as Week 4), this stays simple.

ExampleTotal SpendRegion

Read: About calculated fields (Google).

2. Do 45 min

  1. Create a scorecard on the blend. Insert → Scorecard, Data source = Casework Model.
  2. Add a calculated metric. In Setup, click the metric → Add field / Create field (wording varies). Name it Total Spend, formula SUM(UnitCost), type Currency → Apply.
  3. Make three more scorecards the same way: Total Services, Clients Served and Avg Spend per Client (formulas above). Tip: copy a finished scorecard (⌘ + C / ⌘ + V) and just change its metric.
  4. Table by region. Insert → Table, data source Casework Model. Dimension = Region. Metrics = Total Spend, Clients Served, Avg Spend per Client. Same formulas, five regions, five different answers.
  5. Compare Total Spend with your Week 4 answer. They should match exactly.

Stuck? Try this
  • Error "RELATED… column doesn't exist or doesn't have a relationship": the ServiceCodes→Services relationship is missing. Go back to Week 10, step 2.
  • Red squiggle on a name: table and column names must match exactly, including capitals. Type [ or the table name and pick from the suggestions instead of typing it all.
  • Region table shows the same Total Spend for every region: the Clients→Services relationship isn't working (Week 10).
  • Avg Spend per Client looks like $63: that's the average per service. Check you divided by Clients Served, not Total Services.
Stuck? Try this
  • "Invalid formula": field names must match exactly, including capitals. Start typing and pick from the suggestions.
  • Every region shows the same total: the table isn't using the Casework Model blend, or the Clients join is missing (Week 10).
  • Avg Spend per Client looks like $63: that's the average per service. Divide by COUNT_DISTINCT(ClientID), not COUNT(ServiceID).
  • Total Spend is zero or blank: UnitCost is text. Set its type to Number in the Services data source (Week 9, step 5).

Stretch (optional, 15 min)

Write a measure for spend on Financial Assistance only:

FA Spend = CALCULATE([Total Spend], ServiceCodes[Category] = "Financial Assistance")

CALCULATE is the most powerful function in DAX: "calculate this measure, but with this extra filter." Compare the result with your Week 6 PivotTable.

Make a Financial Assistance-only metric:

FA Spend = SUM(CASE WHEN Category = "Financial Assistance" THEN UnitCost ELSE 0 END)

CASE WHEN is the Looker Studio way of saying "only count these rows." Compare the result with your Week 6 pivot table.
