Week 8 of 16 · Phase 2 · Power Query

Merge, append and refresh

Power Query ⏱ About 90 min

Join tables inside Power Query and add next month's data without starting over.

Why this matters: real reporting is monthly. A new export lands, and you need last month and this month together, with costs attached. Today you do that entirely in Power Query: append September onto the existing data, then merge in the price list. Next month it's one click.

Project spec (exact parameters)

In Casework PQ.xlsx, end up with a query called AllServices that contains:

  • All cleaned services from services_raw.csv plus services_2026-09.csv, cleaned with the same three rules
  • Two extra columns from the price list: UnitCost and Category

Read: Merge queries.

2. Do 70 min

  1. Open Casework PQ.xlsx. Open the Power Query Editor: Data → Get Data (Power Query) → Launch Power Query Editor.
  2. Load the price list. In the editor: Home → New Source → Text/CSV → service_codes.csv. Rename the query ServiceCodes. Check UnitCost's icon is a number (1.2 or $).
  3. Make the September query. In the Queries list on the left, right-click Services → Duplicate. Rename the copy September. In its Applied Steps, click the ⚙ gear next to Source and choose services_2026-09.csv instead. All the cleaning steps now run on the new file.
    No gear icon? Just repeat the Week 7 steps on services_2026-09.csv as a new query called September. Good practice anyway.
  4. Append. Home → Append Queries → Append Queries as New. First table: Services, second: September → OK. Rename the new query AllServices.
  5. Merge. With AllServices selected: Home → Merge Queries. Top table is AllServices; click its ServiceCode column. In the dropdown pick ServiceCodes and click its ServiceCode column. Join kind: Left Outer → OK.
  6. Expand. A new column of "Table" values appears. Click the ⇔ icon in its header, tick only UnitCost and Category, untick Use original column name as prefix → OK.
  7. Load. Home → Close & Load. If Excel loads every query to its own sheet, that's fine. You'll use the AllServices sheet.
  8. Answer the questions. On the AllServices sheet: select the UnitCost column and read Sum in the status bar. Then filter ServiceDate to September 2026 only (date filter arrow → Date Filters → After or Equal To… 2026-09-01) and read the Sum again. Save.

Stuck? Try this
  • UnitCost column is all empty (null): the codes didn't match. Check that the September query has the Trim and UPPERCASE steps, and that you clicked ServiceCode in both tables when merging.
  • Row count is a bit high: the September query is missing the Remove Duplicates or blank-code step.
  • Merge or Append buttons missing: update Excel. If they're still missing, these steps work identically in Power BI's Power Query (Week 9 onward).

You just finished the Excel half of the course. You can clean an export, attach costs, total by client, pivot by program and automate it monthly. That's already more than most people who complain about reports can do.
