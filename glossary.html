Glossary

Every term used in this course, explained with casework examples. Come back here whenever a word feels fuzzy.

Raw data
The individual records straight out of a system, before anyone summarizes them. One row per service, per visit, per payment. Reports are built from raw data; you can't rebuild raw data from a report.
Export
A file (usually CSV or Excel) a system produces when you ask for its data. "Can I get an export of all services for last fiscal year?"
CSV
"Comma-separated values": a plain text file where each line is a row and commas separate the columns. Every system can produce one and every tool can open one.
Row / record
One thing that happened or exists. In services_raw.csv, one row = one service delivered to one client on one day.
Column / field
One piece of information about every row, like ServiceDate or ClientID.
Tidy data
A table where every row is one record, every column is one kind of information, and the top row is the only header. No merged cells, no totals mixed in, no blank rows used for spacing. Tidy data is what every tool in this course expects.
Excel Table
A range you've formatted with Format as Table. It gets a name (like Services), grows automatically when you add rows, and lets you write formulas like Services[ServiceCode] instead of D2:D13568.
ID / key
A column that uniquely identifies each row, e.g. ClientID in the clients table. Keys are how tables connect.
Lookup
Fetching a value from another table by matching an ID. "For this service's code, go find its UnitCost in the price list." In Excel: XLOOKUP.
Aggregate
Combining many rows into one number: sum, count, average, minimum, maximum. "Total spend" is an aggregate.
SUMIFS / COUNTIFS / AVERAGEIFS
Excel functions that aggregate only the rows matching your conditions. SUMIFS(cost, client, "C-0042") = total cost for client C-0042.
PivotTable
Excel's drag-and-drop summarizer. Drop "Program" into Rows and "Cost" into Values and it builds the totals table for you.
Slicer
A panel of buttons that filters a PivotTable or report, e.g. click "North" to see only North region numbers.
Power Query
A tool inside both Excel and Power BI that records your cleaning steps (trim, remove duplicates, merge…) as a reusable recipe. Next month, click Refresh and the same steps run on the new file.
Merge (join)
Combining two tables side by side by matching a key: adding columns. Services + ServiceCodes on ServiceCode gives each service its UnitCost.
Append
Stacking two tables with the same columns on top of each other: adding rows. August's services + September's services = all services.
Semantic model (data model)
Power BI's name for your loaded tables, plus the relationships between them, plus your measures. The "brain" behind a report.
Relationship
A link between two tables in Power BI through a shared key column. Once Clients and Services are related, filtering by Program automatically filters the services.
One-to-many
The most common relationship: one client has many services. The "one" side has unique IDs; the "many" side repeats them.
Fact table / dimension table
A fact table records events (services). Dimension tables describe the who/what/where (clients, codes, workers). A fact table surrounded by dimensions is called a star schema, the recommended shape for Power BI.
DAX
"Data Analysis Expressions": the formula language of Power BI. Looks like Excel formulas but works on whole tables and columns.
Measure
A DAX formula that calculates a number on the fly, based on whatever is filtered: "Total Spend" shows the grand total on a card, and the per-program total in a chart split by program. Use measures for anything you'd sum, count or average.
Calculated column
A DAX formula that adds a new column, computed once for every row (e.g. a Month column from ServiceDate). Use for things you'd filter or group by.
Filter context
The set of filters currently applied to a number: from slicers, chart axes, table rows. It's why one measure can show different values in different places.
Visual
Any chart, table, card or slicer on a Power BI report page.
KPI card
A visual that shows one big number, like "Total Spend: $846K". The top row of most dashboards.
Drill-through
Right-clicking something in a report (like a client) to jump to a detail page filtered to just that thing.
Length of stay
Days between IntakeDate and DischargeDate. Only meaningful for discharged clients.
De-identified data
Data with names and identifying details removed or replaced by codes, so the analysis can't be traced to a person. Always the goal when practising with real work data (see Week 16).
